O que e o QA Flash - UI?

Visao geral do agente de automacao

Um assistente especialista em Engenharia de Qualidade de Software, Arquitetura de Testes e automacao BDD de Interfaces do Usuario (WEB e MOBILE).

Missao: Transformar Historias de Usuario e Criterios de Aceitacao em suites de testes de UI automatizados de alta performance - com velocidade, precisao e rigor tecnico.

🛑 Human-in-the-Loop

O robo nunca avanca de fase sem a aprovacao explicita do QA humano. Cada parada e inegociavel.

🌍 Poliglota

Suporta Java, Python, Cypress/TypeScript e Ruby - em plataforma Web ou Mobile. O QA escolhe a stack.

🏆 Padroes Internacionais

Aplica ISTQB, ISO 29119, principios FIRST, OWASP e LGPD em todo codigo gerado.

🔗 Integracao Total

Conecta ao Jira via MCP, gera codigo no VS Code/Kiro e versiona no GitHub com pipeline CI/CD.

MCP - Model Context Protocol

A ponte entre Kiro e ferramentas externas

O que e?

MCP = Model Context Protocol

Traducao: Protocolo de Contexto do Modelo

E uma ponte que permite o Kiro conversar com ferramentas externas - como Jira, GitHub, bancos de dados - sem voce precisar copiar e colar nada.

Sem MCP: Voce copia a historia do Jira → cola no Kiro → robo executa

Com MCP: Voce diz "busca QA-123" → MCP busca no Jira → robo executa

O que o MCP conecta

FerramentaO que o Kiro faz
JiraLe historias, criterios, status
GitHubLe PRs, issues, codigo
ConfluenceLe documentacoes
SlackEnvia notificacoes

Padroes de Qualidade Aplicados

ISTQB · ISO 29119 · FIRST · OWASP · LGPD

Padrao de Design (POM)

Page Object Model - separacao total entre mapeamento de elementos da tela e scripts de teste. Se a tela mudar, atualiza so o Page Object.

Principio DRY + Padrao AAA

Don't Repeat Yourself - reutilizacao de metodos. Arrange, Act, Assert - estrutura clara: Preparar, Executar, Validar.

Principios FIRST

Fast, Independent, Repeatable, Self-validating, Timely - testes rapidos, independentes, repetiveis e autovalidados.

Locators Resilientes

Permitido: data-testid, data-cy, accessibility-id. Proibido: XPath absoluto, CSS baseado em estrutura visual fragil.

Sincronismo Dinamico

Permitido: espera elemento visivel/clicavel. Proibido: Thread.sleep, time.sleep, cy.wait - pausas estaticas proibidas.

Seguranca (OWASP/LGPD)

Zero credenciais em texto puro. Tudo em variaveis de ambiente (.env). Dados PII nunca em fixtures de teste.
